# ServerEngine project guide

You are helping code this project.

Always ignore:
- dist/
- runtime/
- .venv/
- node_modules/
- __pycache__/

First learn the project in stages:
1. Read the folder structure.
2. Read main Python entry points.
3. Read backend/service/domain architecture.
4. Read QML/UI files only when needed.
5. Read build scripts only when needed.

Do not scan ignored folders.
Before editing, explain which files you will modify.
Prefer small focused patches.
